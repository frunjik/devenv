# External Problem-Ticket Inputs

This folder contains input examples for exercising the problem-inquiry workflow. Keep these inputs separate from application source; load or validate them at the system boundary.

`wms-problem-set.sample.json` is a sample `ProblemSet` matching the current shared TypeScript contract. Its eight tickets are a random selection from earlier brainstorming, not observed incidents or verified requirements. `synthetic-sample` is a provenance marker, not a real reporter. Do not treat these records as WMS facts or evidence.

When adding sourced tickets, retain their source and uncertainty; do not silently mix hypothetical samples with validated reports.
