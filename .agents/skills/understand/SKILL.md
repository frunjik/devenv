# Understand

1. Read available request context and saved decisions before asking for information.
2. Establish the intended outcome, constraints and observable success conditions.
3. Ask about material ambiguity rather than guessing; scale clarification to the request.
4. Hand off the agreed outcome, constraints and success conditions without authorizing unrequested work.
