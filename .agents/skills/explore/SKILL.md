# Explore

1. Inspect relevant sources, tests and callers; distinguish observed facts from assumptions.
2. Identify external dependencies and reuse existing boundary contracts and mocks before writing tests.
3. Compare relevant options, challenge weak assumptions and choose the simplest complete approach.
4. Resolve consequential scope and naming decisions with the user before acting.
5. Hand off evidence, the approach and required approvals; separate investigation does not transfer task ownership.
