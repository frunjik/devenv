# Design or Verify Domain Types

## Trigger
- Execute this skill whenever the user says "define" or "refine".

## Context & Prerequisites
- Make sure that the domain mentioned or implied is known
- There is Glossary with Terms to explain the concepts used in the Domain for which the types are designed

## Workflow Steps
1. Find or Create Terms and Types that cover the meaning of the things in the Domain
2. See if the Terms and Types are present in the Glossary and are correct, or add new ones with a small description.

## Success Criteria
- A good set of Types is found that cover the Domain functionality that is to be expressed in the System.
